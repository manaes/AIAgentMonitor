# ESP32 CYD 외장 디스플레이 설치 & 연결 가이드

AI Agent Monitor는 책상 위에 두고 Claude Code, OpenAI Codex, Antigravity의 사용량과 속도를 실시간으로 확인할 수 있는 **ESP32 CYD(Cheap Yellow Display) 스마트 디스플레이**를 공식 지원합니다.

---

## 1. 준비물

* **ESP32-2432S028R 보드** (2.8인치 240×320 저항막 터치 디스플레이 일체형 ESP32)
* **USB-C 또는 Micro-USB 케이블** (데이터 통신 지원 케이블)
* **PC/Mac 개발 환경**: VS Code + [PlatformIO IDE](https://platformio.org/) 확장 프로그램

---

## 2. STEP 1: 펌웨어 빌드 및 보드 업로드 (플래싱)

### 1) 프로젝트 열기 및 포트 확인
1. VS Code에서 본 프로젝트 루트(`AIAgentMonitor`)를 엽니다.
2. CYD 보드를 USB 케이블로 Mac/PC에 연결합니다.
3. 연결된 시리얼 포트를 확인합니다:
   * **macOS**: 보통 `/dev/cu.usbserial-*` 또는 `/dev/cu.wchusbserial*`
   * **Windows**: `COM3`, `COM4` 등

### 2) 빌드 및 업로드 실행
VS Code 하단의 PlatformIO 툴바에서 **Upload** 버튼(`→`)을 누르거나, 터미널에서 아래 명령을 실행합니다:

```bash
cd firmware/cyd
pio run -e cyd -t upload
```

> **참고**: 만약 특정 시리얼 포트를 명시하고 싶다면 `firmware/cyd/platformio.ini` 파일의 `upload_port` 항목을 수정하거나 `pio run -e cyd -t upload --upload-port /dev/cu.usbserial-1120`과 같이 지정할 수 있습니다.

---

## 3. STEP 2: 와이파이(WiFi) 설정 (캡티브 포털 `AIM-Setup`)

펌웨어 업로드가 완료되면 보드가 자동으로 부팅되며 초기 설정 모드로 진입합니다.

1. **`AIM-Setup` 와이파이 연결**:
   * 스마트폰 또는 노트북의 WiFi 설정에서 **`AIM-Setup`** 와이파이에 연결합니다. (비밀번호 없음)
2. **설정 페이지 접속**:
   * 연결 후 자동으로 캡티브 포털 설정 창이 팝업됩니다.
   * (자동으로 뜨지 않는 경우 웹 브라우저에서 `http://192.168.4.1` 접속)
3. **네트워크 및 호스트 설정**:
   * **WiFi SSID / Password**: 집 또는 사무실에서 사용 중인 2.4GHz WiFi 공유기 정보 입력
   * **Mac Host**: 
     * **비워두기 (권장)**: mDNS(`aim-cyd.local`)를 통해 맥 앱을 자동으로 탐색합니다.
     * 또는 Mac의 로컬 IP 주소(예: `192.168.0.15`)를 직접 입력해도 됩니다.
4. **[Save] 클릭**:
   * 설정이 저장되면 보드가 자동으로 재부팅되며 공유기에 연결됩니다.

---

## 4. STEP 3: 맥 앱에서 공유 켜기 및 6자리 코드 페어링

CYD 보드가 와이파이에 접속되면 화면에 **`Enter Code` 키패드**가 나타납니다.

```text
┌───────────────────────────┐
│ Enter Code                │ ← 상태 타이틀
│ _ _ _ _ _ _               │ ← 6자리 입력란 (파란색)
│ Attempts left: 5          │
├───────────────────────────┤
│ [ 1 ] [ 2 ] [ 3 ]         │
│ [ 4 ] [ 5 ] [ 6 ]         │
│ [ 7 ] [ 8 ] [ 9 ]         │
│ [ < ] [ 0 ] [ OK ]        │
└───────────────────────────┘
```

1. **Mac 앱에서 "CYD 공유" 켜기**:
   * Mac 메뉴바 상단의 **AI Agent Monitor** 아이콘 클릭 → **[Devices]** 탭 이동
   * **"CYD (LAN)" 공유 토글 스위치를 켭니다.** (최초 1회 켜두면 앱 재시작 시에도 자동 유지됨)
   * 화면 중앙에 생성되는 **6자리 인증 코드**(예: `742918`)를 확인합니다.
2. **CYD 보드에서 코드 입력**:
   * CYD 보드의 화면 키패드를 터치하여 맥 앱에 표시된 **6자리 숫자**를 입력합니다.
   * 우측 하단의 **`[ OK ]`** 버튼을 누릅니다.
3. **페어링 완료**:
   * 보드가 맥 앱과 **X25519 & ChaCha20-Poly1305 종단 암호화(E2EE)** 보안 핸드셰이크를 완료하고 토큰을 안전하게 저장합니다.
   * 잠시 `Connecting...` 화면을 거쳐 즉시 **실시간 대시보드 화면**으로 전환됩니다!

---

## 6. 자주 묻는 질문 및 문제 해결 (FAQ & Troubleshooting)

### Q. 화면에 `Connecting...` 라벨만 계속 떠 있습니다.
* **Mac 앱의 "CYD (LAN)" 공유가 켜져 있는지 확인**: Mac 앱의 [Devices] 탭에서 토글이 켜져 있는지 확인해 주세요.
* **동일한 로컬 네트워크(WiFi)인지 확인**: Mac과 CYD 보드가 같은 공유기(서브넷)에 연결되어 있어야 통신이 가능합니다.
* **방화벽 확인**: Mac의 방화벽 설정에서 `AI Agent Monitor` 또는 포트 `4320` 통신이 허용되어 있는지 확인해 주세요.

### Q. WiFi 공유기를 변경하거나 다시 설정하고 싶습니다.
* 보드가 켜질 때 기존 WiFi 접속에 실패하면 자동으로 다시 **`AIM-Setup` AP 모드**가 열립니다. 스마트폰으로 접속하여 새 WiFi 정보를 입력하시면 됩니다.

### Q. 페어링을 초기화하고 다시 연결하고 싶습니다.
* Mac 앱의 [Devices] 탭 하단에서 등록된 기기의 **[Unpair]** 또는 **[모든 기기 연결 해제]** 버튼을 누릅니다.
* CYD 보드는 토큰 무효화를 감지하여 자동으로 기존 자격증명을 지우고 **`Enter Code` 키패드 화면**으로 돌아옵니다. 새 코드를 입력해 다시 페어링하시면 됩니다.
