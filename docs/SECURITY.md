# 페어링과 E2EE 보안 모델

BLE, 원격 네트워크, 로컬 LAN은 같은 v2 애플리케이션 계층 E2EE를 사용한다. 전송 계층 암호화 여부와 무관하게 인가되지 않은 peer에는 사용량 스냅샷을 보내지 않는다.

## 페어링과 재연결

초기 페어링은 Mac 앱이 보여 주는 6자리 코드로 사용자를 확인한다. 코드는 120초 동안 유효하고 창당 최대 5회만 시도할 수 있다. 원격 네트워크 클라이언트는 QR을 사용할 수 있고, 카메라가 없는 CYD는 같은 코드를 화면 키패드로 입력한다.

1. 클라이언트와 Mac은 연결마다 임시 X25519 키쌍을 만든다.
2. 최초 페어링은 `HELLO2`/`CODE2`, 재연결은 `AUTH2`/`PROOF2` 흐름을 사용한다.
3. HKDF-SHA256으로 방향별 키를 도출한다. 재연결 키에는 X25519 공유 비밀과 저장된 128비트 토큰이 함께 들어간다.
4. 최초 토큰도 pairing channel 안에서 봉인해 전달하며 평문으로 전송하지 않는다.
5. 이후 스냅샷은 ChaCha20-Poly1305로 암호화·인증한다.

봉인 프레임은 `counter(8-byte big endian) || ciphertext || tag(16-byte)` 형식이다. 방향별 키를 사용하고 수신 counter가 이전 값 이하이면 replay로 거부한다. 새 연결은 새 임시 키와 새 channel을 사용한다.

## 저장과 운영

- Mac은 peer 식별자, 페어링 시각과 재연결 토큰을, CYD는 토큰과 네트워크 설정을 NVS에 저장한다.
- 로그와 UI에는 토큰 원문을 출력하지 않는다.
- 공유 전송은 기본적으로 꺼져 있다. 필요한 전송만 켜고 페어링 창을 필요 이상 열어 두지 않는다.
- LAN 4320 포트는 같은 네트워크에서 도달 가능하다. E2EE가 내용을 보호하지만 방화벽과 VLAN 분리는 계속 유효하다.
- 예상하지 못한 5회 소진 경고가 나오면 창을 닫고 주변 기기를 확인한다.
- 기기를 분실하거나 양도할 때는 앱에서 peer를 해제하고 CYD 저장 설정도 초기화한다.

바이트 단위 계약과 골든 벡터는 `src-tauri/src/crypto`, `firmware/cyd/lib/cryptov2`, `docs/ble-protocol/golden/`이 함께 검증한다.
