## AI Agent Monitor v1.7.2

### 주요 변경 사항

#### 1. 최신 Codex 세션 저장 형식 지원
- **Codex 0.151+ 호환**: `state_5.sqlite`에 `threads` 테이블이 없는 최신 Codex에서도 `~/.codex/sessions/**/rollout-*.jsonl`을 직접 탐색하여 토큰 사용량을 수집합니다.
- **기존 형식 호환 유지**: 구버전의 `state_5.sqlite` 기반 세션 탐색도 계속 지원합니다.
- **사용량 한도 복원**: 앱 재시작 후에도 최신 rollout에서 5시간 및 주간 사용률과 리셋 시각을 복원합니다.

#### 2. CYD 초기 설정 화면 터치 수정
- **Wi-Fi 포털 대기 중 터치 유지**: WiFiManager 설정 포털이 열려 있는 동안에도 LVGL 타이머와 터치 입력을 계속 처리합니다.
- **첫 연결 UX 개선**: 새 CYD 보드에서 Wi-Fi/Bluetooth 선택 버튼이 표시만 되고 눌리지 않던 문제를 해결했습니다.

### Install
| Platform | File |
|---|---|
| macOS Apple Silicon | `*_aarch64.dmg` |
| macOS Intel | `*_x64.dmg` |
| Windows | `*_x64_en-US.msi` |

macOS 빌드는 Developer ID로 서명 및 공증(Notarized)되어 게이트키퍼 경고 없이 설치할 수 있습니다.
