## AI Agent Monitor v1.2.8

### Added
- **네트워크(P2P) 기기 공유 추가** — BLE 외에 iroh 기반 QUIC 네트워크 전송으로도 iOS 앱과 연결할 수 있습니다. 같은 Wi-Fi에서는 직접 연결, 서로 다른 네트워크에서는 공식 relay 서버를 거쳐 자동으로 연결됩니다.
  - Windows는 BLE가 없어 지금까지 기기 공유를 쓸 수 없었는데, 이번에 네트워크 전송으로 처음 지원됩니다.
  - "공유" 켤 때 BLE/네트워크 중 하나를 선택합니다.
  - 네트워크 선택 시 macOS에 QR 코드가 뜨고, iOS에서 스캔 한 번으로 페어링이 끝납니다(코드를 따로 입력할 필요 없음).
  - 페어링 인증(6자리 코드, 재연결 시 챌린지-응답)은 BLE와 동일한 방식을 그대로 사용합니다.

### Changed
- 세션 상태 단어("idle"/"dormant")와 상대 시각 표기("Xs/m/h ago")를 한글("유휴"/"휴면", "X초/분/시간 전")로 통일했습니다.

### iOS 컴패니언 앱
- 우상단 설정 버튼에서 BLE/네트워크 연결 방식을 전환할 수 있습니다.
- 마지막으로 사용한 연결 방식을 기억해 앱을 다시 열면 그 방식으로 자동 재연결을 시도합니다.

### Install
| Platform | File |
|---|---|
| macOS Apple Silicon | `*_aarch64.dmg` |
| macOS Intel | `*_x64.dmg` |
| Windows | `*_x64_en-US.msi` |

macOS builds are signed and notarized with a Developer ID — no Gatekeeper workaround needed.
