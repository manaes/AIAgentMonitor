## AI Agent Monitor v1.3.0

### Added
- **표시할 에이전트를 고르는 "설정" 탭 추가** — Detail 창의 Sessions/Devices 옆에 설정 탭이 생겼습니다. Claude Code / Codex / Antigravity 중 화면에 표시할 종류를 체크박스로 고를 수 있습니다.
  - 체크를 해제해도 백그라운드 수집은 계속됩니다 — 화면에서만 숨겨지므로, 다시 켜면 그동안의 사용량이 끊김 없이 바로 보입니다.
  - 선택은 `~/.config/ai-agent-monitor/settings.json` 에 저장되어 앱을 다시 열어도 유지됩니다.
  - 에이전트 카드와 세션 목록이 모두 이 선택을 따릅니다.
  - iOS 컴패니언 앱의 미러 화면도 같은 선택을 그대로 반영합니다(맥에서 끄면 iOS에서도 사라집니다).

### Fixed
- 에이전트를 2개 이하로 켰을 때 가로 배치에서 카드 오른쪽에 빈 칸이 남던 문제를 수정했습니다. 이제 켜둔 카드들이 남는 폭을 나눠 갖습니다.

### iOS 컴패니언 앱
- **iOS 16 지원 빌드가 추가됐습니다.** 네트워크(iroh) 전송이 요구하는 iOS 17.5 하한 때문에 그동안 전체 앱이 17.5+ 였는데, BLE 전용 빌드를 따로 만들어 iOS 16 기기에서도 쓸 수 있게 했습니다.
  - `AppBLE` — iOS 16+, BLE 연결만 지원합니다.
  - `App` — iOS 17.5+, BLE와 네트워크(QR 페어링) 모두 지원합니다.
  - 두 빌드는 같은 소스를 공유하므로 기능·화면이 동일하고, 연결 방식만 다릅니다.

### Install
| Platform | File |
