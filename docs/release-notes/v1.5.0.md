## AI Agent Monitor v1.5.0

### Security — 기기 연결이 종단 암호화됩니다

**이번 버전은 이전 버전에 있던 실제 결함을 고칩니다.**

지금까지 아이폰을 페어링할 때, 맥이 발급한 **128비트 토큰이 암호화 없이 그대로 전송**됐습니다. BLE 연결에는 링크 계층 암호화가 걸려 있지 않았기 때문에, 페어링 창이 열려 있는 120초 동안 근처에서 블루투스 통신을 엿듣는 사람은 그 토큰을 통째로 가져갈 수 있었습니다. 토큰은 한 번 새면 이후 언제든 재연결에 쓸 수 있는 장기 자격증명입니다. 화면에 뜨는 **6자리 코드도 평문으로** 오갔습니다.

v1.5.0부터는 그렇지 않습니다.

- **6자리 코드가 더 이상 전송되지 않습니다.** 코드는 이제 양쪽이 만든 임시 키를 묶는 서명 재료로만 쓰입니다. 덕분에 중간에서 통신을 가로채 자기 키를 끼워넣는 공격도 함께 막힙니다 — 그 공격자는 코드를 모르기 때문에 올바른 서명을 만들 수 없습니다.
- **토큰이 발급 순간부터 암호화됩니다.**
- **연결할 때마다 새 임시 키를 만듭니다.** 나중에 토큰이 유출되더라도 그 이전에 녹화해 둔 통신은 풀 수 없습니다.
- **화면에 표시되는 사용량 데이터도 전부 암호화되어 전송됩니다.**

BLE와 네트워크(원격) 연결 모두에 적용됩니다.

### 업데이트 순서가 중요합니다

**맥을 먼저 업데이트하세요. 그다음 iOS 앱입니다.**

맥은 이전 버전 아이폰과 새 버전 아이폰을 **둘 다** 받아들이므로, 맥만 먼저 올려도 기존에 페어링해 둔 아이폰은 그대로 동작합니다. 다시 페어링할 필요 없습니다.

반대로 iOS 앱을 먼저 올리면 새 아이폰이 옛 맥에 붙지 못합니다. 새 앱은 암호화된 방식으로만 연결하기 때문입니다.

### 컴패니언 앱 사용자에게

기존 아이폰은 맥 업데이트 후에도 계속 동작하지만, **암호화의 혜택을 받으려면 iOS 앱도 새 빌드로 올려야 합니다.** 아이폰 앱을 올린 뒤에는 한 번 다시 페어링해 주세요.
