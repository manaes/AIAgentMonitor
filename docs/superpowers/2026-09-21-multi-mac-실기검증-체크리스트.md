# AI Monitor Multi — 실기 검증 체크리스트 (Task 17)

**준비물**: iPhone 실기기 1대, AI Agent Monitor 를 켠 Mac **2대**(네트워크 공유 활성화).
Xcode 에서 `AppMulti` 스킴을 실기기로 Run 한다.

코드 태스크 16개는 전부 구현·리뷰·수정 완료됐고 최종 리뷰가 ✅ 를 냈다.
아래는 **하드웨어 없이는 확인할 수 없는 것만** 모은 것이다. 순서대로 하면 앞 항목이 뒤 항목의 상태를 만들어 준다.

---

## A. 기본 흐름 (먼저)

- [ ] **A1. 첫 Mac 페어링** — `+` → QR 스캔 → **이름 입력창에 Mac 의 실제 이름이 미리 채워져 있는지**(Mac 앱의 `name` 파라미터 동작 증거) → 추가 → 목록에 뜨고 사용량이 채워지는지.
- [ ] **A2. 페어링 대기 화면** — "Mac 에 연결하는 중…" 알림의 스피너 레이아웃이 깨지지 않는지(작은 화면에서도).
- [ ] **A2-1. 페어링 직후 자동 온라인 (QA-1 회귀 확인)** — 페어링을 마치면 목록에서 **손대지 않아도** 온라인이 되는지. 첫 시도가 실패해도 2초·6초 뒤 재시도가 붙어야 한다. 당겨서 새로고침을 해야만 보이면 회귀다.
- [ ] **A3. 둘째 Mac 페어링** — 두 대가 **동시에** 온라인으로 뜨고 각자 tok/s 가 갱신되는지.
- [ ] **A4. 카메라 권한 거부 → 허용** — 권한을 거부해 안내 화면을 띄운 뒤, 설정에서 카메라를 켜고 **앱으로 돌아왔을 때 안내가 걷히고 스캐너가 살아나는지**. (시뮬레이터에서는 권한 변경이 앱을 죽여 확인 불가였다.)

## B. 오프라인 전환 — 이번에 고친 Blocking 의 본체

- [ ] **B1. 자동 복구 경로** — Mac 2 를 잠재우고 **앱을 포어그라운드에 둔 채** 둔다.
      "재연결 중" → 3분 간격 재시도 → "오프라인" 까지 실제로 넘어가는지. **수정 전에는 이 전환 자체가 재현 불가였다.**
- [ ] **B2. 되살아나기** — Mac 2 를 깨우면 다음 3분 타이머(또는 당겨서 새로고침)에 "온라인" 으로 돌아오는지.
- [ ] **B3. 정착 속도** — 꺼진 채 둔 Mac 은 실패 직후 2초·6초 뒤 재시도를 거쳐 **십여 초 안에** "오프라인" 으로 정착해야 한다. 그 뒤로는 3분마다 다시 확인한다. (QA-1 수정 전에는 9분이 걸렸다.)
- [ ] **B4. 격리** — B1 동안 Mac 1 은 영향을 받지 않아야 한다.
- [ ] **B5. 오프라인 표시 규칙** — 오프라인 장치의 tok/s 는 감춰지고 한도 %·막대는 남는지, "N분 전" 이 뜨는지.

## C. 상세 화면 — **한 번도 실행된 적이 없다**

- [ ] **C1. 진입** — 행을 탭해 상세가 뜨고 카드가 그려지는지. 크래시·레이아웃 붕괴가 없는지.
- [ ] **C2. "N분 전" 이 1초마다 움직이는지** — 오프라인 장치 상세를 1~2분 열어 둔다. 카운트다운도 같이 흐르는지.
- [ ] **C3. 진입 재시도** — "재연결 중"/"오프라인" 셀을 탭하면 즉시 재시도가 한 번 걸리는지. 뒤로→재진입을 빠르게 반복해도 중복 probe 가 없는지.
- [ ] **C4. 뒤로 나온 뒤 목록이 계속 갱신되는지** — 상세를 다녀온 장치의 행이 멈추면 안 된다.
- [ ] **C5. 카드 잔상** — 에이전트 2개인 Mac 에서 하나를 끄고 카드가 1개로 줄었다가 다시 2개가 될 때, 점 색·모델명·카운트다운·막대가 이전 값으로 남지 않는지.
- [ ] **C6. 온라인 → 오프라인 전이를 상세를 열어둔 채** 겪게 한다. tok/s 가 사라지고 한도는 남는지.
- [ ] **C7. 뒤로 나온 뒤 CPU 가 내려가는지** — 목록에 머무를 때 1초 틱이 멈췄는지.
- [ ] **C8. 스와이프 뒤로가기 중간 취소** 를 여러 번 반복한 뒤에도 시각 표시가 1초에 한 칸씩만 움직이는지(중복 타이머 없음).
- [ ] **C9. 가로모드** — 카드가 세로로만 쌓여 한 장도 다 안 보이는지. 1:1 앱과 비교해 문제면 알려줘.

## D. 재페어링 경로 (Mac 2대 필요)

Mac 1 에서 페어링을 취소하거나 앱을 재설치해 `재페어링 필요` 를 만든 뒤:

- [ ] **D1. 셀을 탭하면 스캐너가 열리는지.** 타이틀이 "재페어링"(`+` 는 "장치 추가"). 상세로 가면 배선 실패다.
- [ ] **D2. 다른 Mac 의 QR 을 대본다.** "…의 QR 이 아닙니다" 안내가 뜨고, 확인 후 **같은 화면에서 올바른 QR 이 다시 읽히는지**. 여기서 멈추면 스캔 잠금이 안 풀린 것이다 — 이 앱의 과거 버그 유형이다.
- [ ] **D3. 올바른 QR 로 끝까지** — 복구되고 **이름과 정렬 순서가 보존**되는지. 새 행이 하나 더 생기면 병합 실패다.
- [ ] **D4. 상세를 연 채 토큰 폐기** — 상세 문구가 바뀌는지 → 뒤로 → 셀 탭 → 재페어링 스캐너로 가는지.

## E. 드래그 재정렬 (이번에 새로 만든 기능)

- [ ] **E1. 기본** — 같은 그룹 안에서 끌어다 놓으면 순서가 바뀌고, **앱을 완전히 종료했다 다시 켜도** 유지되는지.
- [ ] **E2. 그룹 가로지르기 거절** — 온라인 셀을 오프라인 그룹으로 끌면 놓아도 제자리로 돌아오는지.
- [ ] **E3. 맨 끝으로 놓기** — 마지막 셀 **아래 빈 영역**에 놓을 때 이동이 되는지, 튕기는지.
- [ ] **E4. 스트리밍 중 드래그** — 매초 갱신 중에 드래그를 3~5초 붙들었다 놓는다. 3분 타이머가 발화하는 순간을 노려 한 번. 목록이 손가락 밑에서 재정렬될 때 의도한 자리에 놓이는지, 크래시가 없는지.
- [ ] **E5. 스와이프 삭제와 충돌** — 길게 눌러 드래그 / 옆으로 밀어 삭제가 서로를 잡아먹지 않는지.

## F. 삭제·한도

- [ ] **F1. 삭제 → 재페어링** — 장치를 지우고 같은 Mac 을 다시 페어링했을 때 **연결 전에 낡은 값이 보이지 않는지**.
- [ ] **F2. 16대 한도 안내** — 16대를 채운 상태에서 `+` 를 누르면 "새 장치는 못 받지만 재스캔 갱신은 가능" 안내가 뜨는지.
- [ ] **F3. 16대에서 재페어링** — 한도 알림 없이 D 경로가 그대로 되는지.

## G. 부하·성능 (여유 있을 때)

- [ ] **G1. 포어그라운드 복귀** — 앱을 백그라운드로 보냈다 돌아오면 전 장치가 다시 붙는지.
- [ ] **G2. 16대 재탐색 중 스트리밍 유지** — 3분 타이머가 발화하는 순간 온라인 장치 화면이 멈추지 않는지.
- [ ] **G3. 목록 스크롤 체감** — 셀 재구성이 매초 도는 상태에서 스크롤이 끊기는지.
- [ ] **G4. 메인 스레드 점유** — Instruments Time Profiler 로 복호화·JSON 디코드 비율. 유의미하면 알려줘.

## H. 기존 앱 회귀 (중요)

- [ ] **H2. `AppBLE`** — BLE 연결.
