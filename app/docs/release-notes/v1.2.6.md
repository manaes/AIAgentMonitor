## AI Agent Monitor v1.2.6

### Added
- Antigravity 에이전트 사용량/한도 측정 추가
- iOS 컴패니언 앱: BLE 페어링 프로토콜 및 세션 미러 화면 추가 (토큰 기반 기기 인증, 페어링 코드 발급/해제 UI, nonce 챌린지-응답 재인증)

### Fixed
- 공유 끄기/전원 꺼짐 시 세션 인가 상태 정리
- 인가된 central에만 스냅샷을 전송하도록 BLE 전송 경로 전체에 대상 제한 적용
- 페어링 토큰 저장 실패가 조용히 무시되지 않고 오류로 노출되도록 수정
- 남은 임시 파일이 이후 페어링 토큰 저장을 영구히 막던 문제 수정

### Install
| Platform | File |
|---|---|
| macOS Apple Silicon | `*_aarch64.dmg` |
| macOS Intel | `*_x64.dmg` |
| Windows | `*_x64_en-US.msi` |

macOS builds are signed and notarized with a Developer ID — no Gatekeeper workaround needed.
