## AI Agent Monitor v0.1.5

Claude quota utilization values above 100% are now displayed correctly.

### Changed
- Fixed Claude 5h quota display when Anthropic reports utilization as a ratio above `1.0` (for example, `1.01` now displays as `100%`, not `1%`).
- Added regression tests for Claude quota utilization conversion below and above 100%.
- Bumped app version metadata to `0.1.5`.

### Verification
- `rtk cargo test` passed with 38 tests.

### Install
| Platform | File |
|---|---|
| macOS Apple Silicon | `*_aarch64.dmg` |
| macOS Intel | `*_x64.dmg` |
| Windows | `*_x64_en-US.msi` |

On macOS, if Gatekeeper blocks the first launch:

```bash
xattr -cr "/Applications/AI Agent Monitor.app"
```
