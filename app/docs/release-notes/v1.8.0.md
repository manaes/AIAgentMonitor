## AI Agent Monitor v1.8.0

### 주요 변경 사항

#### 1. 메뉴바 아이콘이 사용량에 맞춰 움직입니다
- 모든 에이전트의 tok/s 합계에 비례해 macOS 메뉴바 아이콘이 이퀄라이저 바 애니메이션으로 순환합니다. 유휴 상태에서는 느리게(900ms), 활발하게 작업 중이면 빠르게(90ms) 움직여 창을 열지 않아도 지금 작업이 돌고 있는지 알 수 있습니다.
- 앱 안의 에이전트 카드에도 같은 원리의 상태 점(pulse)을 추가했습니다.

#### 2. 상세 창이 넓어졌습니다
- 기본 창 크기를 720x560 → 1100x720으로 키웠습니다. 에이전트와 세션이 여러 개일 때 가로로 잘리던 항목들이 한눈에 들어옵니다.

#### 3. 이미 소진된 페어링 코드가 화면에 남아 있던 문제 수정
- BLE·네트워크·LAN은 하나의 페어링 창을 공유합니다. 어느 한쪽으로 페어링이 성공하면 창은 즉시 닫히지만, Mac 화면은 이를 알지 못해 이미 무효가 된 QR 코드와 6자리 코드를 계속 보여줬습니다.
- 그 상태의 QR을 다른 기기가 스캔하면 Mac이 거절을 돌려주고, 기기는 "페어링 필요" 상태에서 멈춰 버렸습니다.
- 이제 어느 전송으로든 페어링이 완료되는 즉시 화면에서 QR/코드가 사라집니다.

### iOS 미러 앱 (TestFlight)

- **홈 화면 위젯을 추가했습니다.** 앱을 열지 않아도 에이전트별 5시간·주간 사용량과 그래프를 홈 화면에서 바로 볼 수 있습니다. 위젯 안의 새로고침 버튼을 누르면 앱을 열지 않고 그 자리에서 최신 값을 받아옵니다.
- Mac과 연결이 안 되는 상황에서도 마지막으로 받아둔 값과 갱신 시각을 함께 보여줍니다.
- 최초 실행 시 연결 방식(BLE/네트워크)을 먼저 고르는 화면과, 설정의 "연결 재설정"을 추가했습니다.

### CYD 보드 펌웨어

- 카드의 에이전트 이름 좌측에 상태 점을 추가하고, Mac·iOS와 같은 방식으로 tok/s에 비례해 깜빡이도록 했습니다.

### Install
| Platform | File |
|---|---|
| macOS Apple Silicon | `*_aarch64.dmg` |
| macOS Intel | `*_x64.dmg` |
| Windows | `*_x64_en-US.msi` |

macOS 빌드는 Developer ID로 서명 및 공증(Notarized)되어 게이트키퍼 경고 없이 설치할 수 있습니다.
