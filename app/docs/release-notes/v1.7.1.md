## AI Agent Monitor v1.7.1

### 주요 변경 사항

#### 1. ESP32 CYD(외장 디스플레이) Bluetooth LE (BLE) 무선 연동 지원
- **BLE 무선 미러링**: Wi-Fi 공유기가 없거나 네트워크 연결이 제한된 환경에서도 Mac과 CYD 보드 간 블루투스(BLE)로 직접 연결하여 실시간 에이전트 대시보드를 사용할 수 있습니다.
- **X25519 & ChaCha20-Poly1305 E2EE**: BLE 통신 채널 상에서도 6자리 핀코드 페어링 및 종단간 암호화 보안 세션을 완벽하게 지원합니다.
- **Wi-Fi / BLE 듀얼 모드 스위칭**: CYD 보드 화면에서 `Wi-Fi (LAN)`와 `Bluetooth (BLE)` 모드를 원터치로 손쉽게 전환할 수 있으며, 선택한 모드는 보드 NVS 메모리에 영속화되어 재부팅 후에도 유지됩니다.

#### 2. 실시간 tok/s 속도 단위 단축 표기 (k / M)
- **가독성 향상**: 1,000 이상의 높은 토큰 생성 속도를 `2.1k tok/s`, `15.0k tok/s`, `1.5M tok/s` 형태로 자동 축약하여 CYD 보드와 데스크톱 앱 화면에서 더욱 명확하고 시인성 높게 표시합니다.

#### 3. BLE 통신 안정화 및 ESP32 수신 메모리 최적화
- **안전 청크 캡핑(240B)**: ESP32 NimBLE 스택의 수신 메모리 풀(mbuf) 고갈 및 패킷 손상을 방지하기 위해 Mac 측 송신 청크 크기를 240바이트로 안전하게 캡핑하여 패킷 유실을 원천 방지했습니다.
- **GATT 구독 즉시 자동 리프레시**: BLE 연결 즉시 최신 스냅샷을 강제 송출하여 연결 직후 빈 화면 정체 현상을 해결했습니다.
- **터치 드라이버 좌표 클램핑**: 터치 컨트롤러 경계값(X=240) 워닝 폭주를 해결하여 LVGL 렌더링 안정성을 극대화했습니다.

|---|---|
