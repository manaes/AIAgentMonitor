## AI Agent Monitor v1.7.9

### 주요 변경 사항

#### 1. macOS 26/27에서 메뉴바 아이콘을 좌클릭해도 팝오버가 뜨지 않던 문제 수정
- macOS 27(Golden Gate)부터 `NSStatusItem`에 메뉴가 붙어 있으면 좌클릭이 트레이 아이콘의 이벤트 처리 뷰까지 전달되지 않습니다. 클릭 이벤트 자체가 발생하지 않아 팝오버 토글이 실행되지 않고, 대신 우클릭 메뉴만 떴습니다.
- 메뉴를 상시로 붙여 두지 않고 클릭을 받은 직후에만 잠깐 연결했다 떼도록 고쳤습니다. 좌클릭 → 팝오버, 우클릭 → 메뉴가 모두 정상 동작합니다.
- 업스트림([tauri-apps/tray-icon#355](https://github.com/tauri-apps/tray-icon/issues/355))의 수정이 아직 반영되지 않아 해당 크레이트를 로컬에 포함해 적용했습니다.

#### 2. Codex 5h 한도가 빈칸으로 사라지던 문제 수정
- 2026년 9월 Codex 업데이트 이후 일부 요금제는 5시간 한도 창을 더 이상 보고하지 않고 주간 한도만 돌려줍니다. 이때 카드에서 5h 항목이 통째로 사라져 에이전트마다 카드 높이가 달라졌습니다.
- 5h·주간 항목과 그래프를 **항상** 표시하도록 바꿨습니다. 한도를 받을 수 없는 항목은 "지원하지 않음"으로 표시하고 그래프는 0%로 비워 둡니다. 5h 한도가 없는 경우에도 앱이 직접 집계한 5시간 토큰 사용량은 같은 줄에 계속 보여줍니다.
- 아직 동기화 전인 상태("동기화 전")와 해당 요금제가 제공하지 않는 상태("지원하지 않음")를 구분해 표시합니다.

#### 3. 사라진 한도 값이 옛날 숫자로 남아 있던 문제 수정
- 한도 조회 응답에 특정 창이 빠져 있어도 이전에 받아둔 값을 지우지 않아, 갱신될 일이 없는 낡은 사용률이 카드에 그대로 남을 수 있었습니다.
- 능동 조회 응답은 계정 한도 전체이므로, 응답에 없는 창은 지우도록 했습니다. 과거 대화 기록에서 읽어온 조각난 값은 종전처럼 유지합니다.

| macOS Intel | `*_x64.dmg` |
| Windows | `*_x64_en-US.msi` |

macOS 빌드는 Developer ID로 서명 및 공증(Notarized)되어 게이트키퍼 경고 없이 설치할 수 있습니다.
