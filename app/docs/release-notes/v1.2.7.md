## AI Agent Monitor v1.2.7

### Removed
- Anchor Trigger(예약 실행) 기능 제거 — 정해진 시각에 자동으로 프롬프트를 발사하던 기능과 관련 설정 화면·백엔드 스케줄러를 모두 걷어냈습니다.

### Fixed
- 5h/주간 사용량 리셋 카운트다운이 "2h 34m 12s" 영문 축약 표기로 나오던 문제 수정 — iOS 미러 화면과 동일하게 "약 2시간 34분 12초 남음" 표기로 통일했습니다.

### iOS 컴패니언 앱
- 앱 이름을 "AI Monitor"로 변경하고 전용 아이콘 추가
- 화면 하나뿐인 구성에서 장식으로만 남아있던 상단 네비게이션바 제거, 연결 상태는 좌상단 라벨로 표시
- 가로모드에서 에이전트 카드 3개가 한 줄에 나란히 보이도록 레이아웃 개선

### Install
| Platform | File |
|---|---|
| macOS Apple Silicon | `*_aarch64.dmg` |
| macOS Intel | `*_x64.dmg` |
| Windows | `*_x64_en-US.msi` |

macOS builds are signed and notarized with a Developer ID — no Gatekeeper workaround needed.
