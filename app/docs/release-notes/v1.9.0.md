## AI Agent Monitor v1.9.0

### 주요 변경 사항

#### 1. TestHub 진행 중 테스트를 CYD 보드에 표시합니다
- TestHub의 자동화(API/UI/보안 점검)와 단독으로 시작한 보안 점검을 읽어, 진행 중인 단계를 CI job 목록 맨 위에 `TestHub` 행으로 보여줍니다. 진행률과 경과 시간이 함께 나옵니다.
- `~/.config/ci-status/testhub.url`(예: `http://host:8090`)에 TestHub 주소를 한 줄 적으면 켜지고, 파일이 없으면 꺼집니다.
- 보안 점검 진행률은 영역 수 기반 추정치입니다.

#### 2. 로컬 네트워크 권한 안내
- 같은 네트워크의 TestHub에 접근하므로, 처음 실행하면 macOS가 로컬 네트워크 권한을 물을 수 있습니다. 허용해 주세요.

---

### Install
| Platform | File |
|---|---|
| macOS Apple Silicon | `*_aarch64.dmg` |
| macOS Intel | `*_x64.dmg` |
| Windows | `*_x64_en-US.msi` |

macOS 빌드는 Developer ID로 서명 및 공증(Notarized)되어 게이트키퍼 경고 없이 설치할 수 있습니다.
