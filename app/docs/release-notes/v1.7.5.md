## AI Agent Monitor v1.7.5

### 주요 변경 사항

#### 1. quota 동기화용 "ping" 세션이 목록에 뜨던 문제 수정
- 5h/주간 사용률(%)을 유휴 중에도 최신 상태로 유지하려고 백그라운드에서 주기적으로 `claude -p ping`을 실행하는데, 이게 실제 작업 세션처럼 세션 목록에 "ping"이라는 항목으로 그대로 노출됐습니다. quota % 캡처 방식은 그대로 두고, 이 합성 세션만 목록에서 제외했습니다.

#### 2. 세션 목록 색상/정리 개선
- Codex가 활동 중일 때 유휴(주황) 상태와 같은 색으로 표시되어 구분이 안 되던 문제를 고쳐, Codex 전용 색을 배정했습니다.
- 방치된 세션을 6시간 뒤에 지우던 것을, 유휴→휴면 경계(5분)로 당겼습니다. 휴면(회색) 세션은 더 이상 목록에 남지 않고, 그 경계를 넘는 즉시 정리됩니다. 부수 효과로 BLE/LAN 미러 페이로드가 더 작고 안정적으로 유지됩니다(v1.7.4의 CYD 연결 반복 끊김 수정과 같은 방향).

| Platform | File |
|---|---|
| macOS Apple Silicon | `*_aarch64.dmg` |
| macOS Intel | `*_x64.dmg` |
| Windows | `*_x64_en-US.msi` |

macOS 빌드는 Developer ID로 서명 및 공증(Notarized)되어 게이트키퍼 경고 없이 설치할 수 있습니다.
