## AI Agent Monitor v1.7.4

### 주요 변경 사항

#### 1. CYD 보드 연결 반복 끊김 수정
- v1.7.3에서 세션별 집계로 바꾸면서, 종료된 세션이 내부 목록에서 전혀 정리되지 않아 앱을 켜둔 시간에 비례해 BLE로 보내는 스냅샷이 계속 커지는 문제가 있었습니다. 페이로드가 커질수록 CYD 보드가 45초 안에 완전한 프레임을 못 받아 연결이 끊기고 다시 붙기를 반복했습니다.
- 6시간 넘게 방치된(Dormant) 세션은 내부 목록에서 완전히 제거해, 스냅샷 크기가 무한정 커지지 않도록 고쳤습니다.

### Install
| Platform | File |
|---|---|
| macOS Apple Silicon | `*_aarch64.dmg` |
| macOS Intel | `*_x64.dmg` |
| Windows | `*_x64_en-US.msi` |

macOS 빌드는 Developer ID로 서명 및 공증(Notarized)되어 게이트키퍼 경고 없이 설치할 수 있습니다.
