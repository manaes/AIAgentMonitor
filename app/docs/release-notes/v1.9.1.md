## AI Agent Monitor v1.9.1

### 주요 변경 사항

#### 1. 네트워크 라이브러리(iroh) 1.5.0으로 업데이트
- 연결에 쓰는 iroh를 1.0.3에서 1.5.0으로 올렸습니다. 연결 안정성과 보안 수정이 포함되어 있습니다.
- 사용 방법과 화면은 바뀌지 않습니다.

#### 2. CYD 보드: 한도 소진 시 리셋 카운트다운 표시
- 사용 한도를 모두 쓴 경우에도 리셋까지 남은 시간이 표시됩니다.

---

### Install
| Platform | File |
|---|---|
| macOS Apple Silicon | `*_aarch64.dmg` |
| macOS Intel | `*_x64.dmg` |
| Windows | `*_x64_en-US.msi` |

macOS 빌드는 Developer ID로 서명 및 공증(Notarized)되어 게이트키퍼 경고 없이 설치할 수 있습니다.
