## AI Agent Monitor v1.8.1

### 주요 변경 사항

#### 1. CI 작업 현황을 CYD 보드로 보냅니다
- CIStatusBar가 내보내는 `status.json`의 최근 CI job을 읽어 CYD/iOS 미러 스냅샷(`j[]`)에 함께 실어 보냅니다.

#### 2. Claude 5시간·주간 리셋 시각 보정
- `claude /usage`가 알려주는 "resets" 문구에서 5시간/주간 리셋 시각을 읽어 채웁니다. 리셋 시각이 비어 보이던 경우가 줄어듭니다.

### iOS 미러 앱 (TestFlight)

- **여러 대의 Mac을 등록해서 볼 수 있습니다.** QR 스캔 → 코드 페어링으로 장치를 추가하고(최대 16대), 장치 목록에서 개별/통합 보기를 전환합니다.
- 통합 보기는 장치별 상태와 상관없이 가장 최근 값을 기준으로 한도를 합산합니다. 에이전트별 속도 카드도 가로로 나란히 보여줍니다.
- 장치 상세 화면(오프라인 진입 시 1회 재시도), 가로 모드 카드 배치, 드래그로 목록 순서 변경을 추가했습니다.
- 재페어링이 필요한 장치를 탭하면 해당 장치의 QR만 받는 재스캔으로 이어집니다.
- 연결 안정성을 개선했습니다: 실패 직후 짧게 재시도해 "재연결 중"에서 멈추던 문제, 첫 스냅샷 뒤 갱신이 멈추던 문제, 한도 막대가 목록에서 안 보이던 문제, 장치 삭제 뒤 캐시가 되살아나던 문제를 수정했습니다.

### CYD 보드 펌웨어

- **가로형 CI job 대시보드 화면을 추가했습니다.** 진행 중 job은 링이 실제 진행률을 따라가고, 게이지의 리셋 시간은 tok/s 아래에 표시합니다.

### Install
| Platform | File |
|---|---|
| macOS Apple Silicon | `*_aarch64.dmg` |
| macOS Intel | `*_x64.dmg` |
| Windows | `*_x64_en-US.msi` |

macOS 빌드는 Developer ID로 서명 및 공증(Notarized)되어 게이트키퍼 경고 없이 설치할 수 있습니다.
