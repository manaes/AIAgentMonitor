## AI Agent Monitor v1.7.3

### 주요 변경 사항

#### 1. 세션별 정확한 추적 (버그 수정)
- **동일 폴더 내 다중 세션 구분**: 같은 프로젝트 폴더에서 세션(예: Claude Code 창) 두 개가 동시에 돌면 예전엔 나중 이벤트가 이전 세션 정보를 덮어써 하나만 보였습니다. 이제 세션 ID 단위로 집계해 각자 따로 표시됩니다.
- **세션별 최근 메시지 미리보기**: 활성 세션 목록에 최근 사용자 메시지의 짧은 미리보기를 추가했습니다(데스크톱 화면 전용, BLE/LAN 미러로는 전송되지 않습니다).

#### 2. 쿼터 리셋 후 표시 값 정합성 수정
- 5시간/주간 사용량 창이 리셋된 뒤에도, 다음 실제 API 응답을 관측하기 전까지는 리셋 이전(만료된 창)의 사용률(%)이 그대로 남아있던 문제를 고쳤습니다. 리셋 시각이 지나면 새 관측이 들어오기 전까지 0%로 표시합니다.

#### 3. CYD 보드 BLE 간헐적 연결 끊김 완화
- 대시보드 카드 3개를 매번 동시에 갱신하던 것을 카드 1장씩 순환 갱신하도록 바꿔, 화면 갱신이 유발하던 순간적인 지연(최대 ~135ms → ~57ms)을 절반 이하로 줄였습니다.
- BLE 연결 감독 타임아웃을 재조정해 순간적인 지연에 좀 더 관대해지도록 했습니다.
- WiFi 모드에서 처음 페어링할 때 코드 입력 키패드가 뜨지 않고 멈춰 있던 데드락을 수정했습니다.

### Install
| Platform | File |
|---|---|
| macOS Apple Silicon | `*_aarch64.dmg` |
| macOS Intel | `*_x64.dmg` |
| Windows | `*_x64_en-US.msi` |

macOS 빌드는 Developer ID로 서명 및 공증(Notarized)되어 게이트키퍼 경고 없이 설치할 수 있습니다.
