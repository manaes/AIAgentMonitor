## AI Agent Monitor v0.1.6

Automatic app updates are now enabled.

### Changed
- Added Tauri updater integration that checks for updates shortly after app startup.
- Downloads, verifies, installs, and restarts automatically when a newer signed release is available.
- Configured release builds to generate updater artifacts and use GitHub Releases `latest.json`.
- Added GitHub Actions signing environment variables for updater artifacts.

### Verification
- `rtk cargo test` passed with 38 tests.

### Release Requirement
- GitHub repository secrets must include `TAURI_SIGNING_PRIVATE_KEY`.
- `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` may be empty because the generated local updater key has no password.

### Install
| Platform | File |
|---|---|
| macOS Apple Silicon | `*_aarch64.dmg` |
| macOS Intel | `*_x64.dmg` |
| Windows | `*_x64_en-US.msi` |

On macOS, if Gatekeeper blocks the first launch:

```bash
xattr -cr "/Applications/AI Agent Monitor.app"
```
