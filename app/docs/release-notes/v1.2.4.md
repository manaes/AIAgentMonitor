## AI Agent Monitor v1.2.4

Claude Code and Codex token usage monitoring for your menu bar.

### Changes
- 보안 강화:
  - webview에 엄격한 CSP(Content Security Policy) 적용
  - 미사용 shell 플러그인/권한 제거 (공격면 축소)
  - 트리거 추가 시 agent/시각/프롬프트 입력 검증 추가
  - quota 프록시 요청 바디 크기 상한(64MB) 적용
- 의존성 업데이트: vite 5 → 6 (dev 서버 moderate 취약점 2건 해소)

### Install
| Platform | File |
|---|---|
| macOS Apple Silicon | `*_aarch64.dmg` |
| macOS Intel | `*_x64.dmg` |
| Windows | `*_x64_en-US.msi` |

macOS builds are signed and notarized with a Developer ID — no Gatekeeper workaround needed.
