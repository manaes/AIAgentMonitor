## AI Agent Monitor v1.7.8

### 주요 변경 사항

#### 1. Claude 5h/주간 사용률이 0%로 잘못 표시되던 문제 수정
- `/usage` 안전망은 %만 갱신하고 reset 시각(`reset_at`)은 건드리지 않는데, 화면 표시 로직은 "reset 시각이 지났으면 창이 만료된 것 — 0%로 표시"라는 규칙을 갖고 있었습니다. 실제 5h/주간 창이 리셋된 뒤에도 그 사이 로컬 프록시를 거치는 트래픽이 없었다면 캐시된 reset 시각이 과거로 남아있어, `/usage`로 정확히 받아온 최신 %(예: 7%/1%)가 카드에는 0%로 덮어써 보였습니다.
- 새 %를 받을 때 이미 지난 reset 시각은 지우도록 고쳐, 최신 %가 그대로 표시되도록 했습니다. 아직 유효한 reset 시각은 그대로 유지됩니다(카운트다운 표시용).
